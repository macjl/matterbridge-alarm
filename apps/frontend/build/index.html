Triggers

Select an accessory, then a state or transition. An existing state can trigger as soon as the alarm is armed. A transition triggers only when it happens during monitoring. Add the trigger to one or more zones in the Zones tab.

TriggerAccessoryConditionStatusCommands
Create a trigger

Transitions cover on/off, open/closed, and detected/clear. The exit delay ignores transitions. Reconnecting establishes a new baseline for transitions.

Zones

A zone signals an intrusion when any of its triggers matches. A trigger can belong to multiple zones.

Actions

An action runs commands in order. Group your actions in the Scenarios tab.

To play a sound, select Play a profile on the Audio player. A stop action can run on disarm or rearm. You can run an action manually while the alarm is disarmed.

ActionCommand sequenceCommands
Create an action
    Available commands depend on the accessory. Setting brightness can turn a light on. Changing color or white temperature preserves the current brightness.
